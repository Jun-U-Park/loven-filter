# 개인정보처리방침

로벤 인장 필터 0.6.0 · 개정 시행일: 2026년 10월 21일

개발자: Jun-U-Park
문의: https://github.com/Jun-U-Park/loven-filter/issues

## 목적과 처리 정보

이 확장 프로그램은 로스트아크 인벤 게시판 작성자의 공개 인장 및 게임 프로필 정보를 확인해 닉네임 옆에 상태를 표시하고, 사용자가 선택한 색상에 따라 게시글과 댓글을 숨기거나 표시합니다.

PC(www.inven.co.kr) 및 모바일(m.inven.co.kr)의 로스트아크 게시판에서 현재 페이지의 작성자 닉네임과 인증마크 유무를 읽습니다. 이용자가 게시글의 추천확인 명단을 펼치면 추천·비공감 명단의 공개 닉네임도 읽어 동일한 인장 검증과 색상별 인원 집계에 사용합니다. 명단 자체나 추천·비공감 관계는 별도로 저장하지 않습니다. 필요한 경우 인벤 인장 페이지에서 회원 식별자를 확인하고, 인벤의 게임 프로필 조회 주소로 닉네임과 회원 식별자를 보내 공개 프로필의 인증 상태, 갱신일, 전투력, 아이템 레벨 등을 확인합니다. 응답의 일부 필드는 인증 상태 확인에만 사용하며 전체 응답과 회원 식별자는 저장하지 않습니다. 게시글·댓글 본문, 비밀번호, 로그인 쿠키는 수집·저장하지 않습니다.

## 통신과 공유

조회 통신은 HTTPS www.inven.co.kr의 인장 및 게임 프로필 조회 주소로만 수행합니다. 로그인 쿠키는 요청에서 제외합니다. 인벤은 요청 처리 과정에서 조회에 필요한 닉네임·회원 식별자와 통상적인 접속 정보(IP 주소 등)를 받을 수 있으며, 해당 사이트의 서버 기록은 인벤의 정책에 따릅니다.

개발자는 확장 프로그램의 사용자 정보나 조회 결과를 전달받지 않습니다. 개발자 서버, 광고·분석 서비스, 정보 판매 또는 기타 제3자 전송 기능은 없습니다. Chrome 웹스토어와 GitHub를 이용할 때 해당 서비스가 처리하는 정보는 각 서비스의 정책에 따릅니다.

## PC에 저장하는 정보

Chrome의 확장 프로그램 전용 로컬 저장소에 설정과 닉네임별 판정 상태, 조회·만료 시각, 짧은 실패 사유, 갱신일·전투력·아이템 레벨, 캐시 초기화 번호를 저장합니다. 또한 설정 팝업의 접음·펼침 상태, 업데이트 안내 확인 버전, 중복 안내를 방지하기 위한 임시 표시 권한(버전·탭 번호·무작위 토큰·만료 시각)을 저장합니다. Chrome 계정 동기화를 이용하지 않습니다.

정상 결과의 캐시 유효기간은 30분, 실패 결과는 30초입니다. 만료는 즉시 물리적인 삭제를 뜻하지 않습니다. Chrome 시작 시 및 조회 활동 중 정리하며, 정리 시 최근 최대 1,500개를 유지합니다. 설정은 변경하거나 확장 프로그램을 제거할 때까지 유지됩니다.

## 이용자의 제어와 삭제

설정의 전체 스위치로 조회와 필터 기능을 끌 수 있습니다. ‘인장 검증 새로고침’은 저장된 판정 캐시를 삭제하고, 기능이 켜져 있으면 현재 페이지를 다시 검증합니다. 캐시 삭제만 원하면 먼저 전체 스위치를 끈 뒤 새로고침 버튼을 누르세요. Chrome에서 확장 프로그램을 제거하면 확장 프로그램의 로컬 설정과 저장 데이터도 제거됩니다.

## 제한된 사용과 변경

처리 정보는 설명된 프로필 판정 및 필터 기능에만 사용하며 Chrome 웹스토어 사용자 데이터 정책의 제한된 사용 요구사항을 준수합니다. 데이터 처리 방식이 바뀌면 방침과 필요한 제품 안내를 함께 갱신합니다. 문의에 개인정보나 계정 인증정보를 공개 게시하지 마세요.
