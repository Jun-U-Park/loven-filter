# 로벤 인장 필터 0.6.0

## 0.6.0 — 2026-10-21

- 게시글/댓글 숨김 옵션 분리
- 화면 하단 통계 패널 표시/숨김 옵션 추가 및 좌측·우측 위치 선택
- 게시글 내 추천 확인 시 명단 색상 및 통계 추가: 검은색 합계와 색상별 인원을 9,999까지 고정 폭으로 표시하며 하단 통계 패널에서는 제외
- 추천·비공감 명단은 검증 캐시를 우선 사용하고 기존 동시 10명 제한으로 순차 검증
- 설정 팝업의 설명·인장 기준 접음/펼침 상태 저장
- 업데이트 후 최초 안내 및 설정 설명 안의 ‘업데이트 내역 보기’ 버튼 추가
- 모바일 인벤 게시판 지원과 설정 스위치 배치 개선 포함

업데이트 안내 제목은 ‘로벤 인장 필터가 0.6.0으로 업데이트되었습니다.’이며, 안내 목록은 다음 세 항목을 사용합니다.

1. 게시글/댓글 숨김 옵션 분리
2. 화면 하단 통계 패널 표시/숨김 옵션 추가
3. 게시글 내 추천 확인 시 명단 색상 및 통계 추가

기존 설정을 유지하며 새로 추가된 설정에만 기본값을 적용합니다. 현재 작업 폴더는 0.6.0 업로드용입니다. 웹스토어 심사 제출은 별도로 진행합니다.

## 0.5.8 추천·비공감 명단 인장 표시

설정의 ‘상태 패널 표시’ 명칭을 ‘통계 패널 표시’로 변경했습니다. 기존 사용자는 업데이트 후 처음 인벤 게시판을 열 때 변경 내역 안내를 받습니다. 확인한 버전은 기기에 저장하며 처음 설치한 사용자에게는 생략합니다. 설정 팝업의 ‘확장 프로그램 설명’ 안에 있는 작은 ‘업데이트 내역 보기’ 버튼으로 같은 안내를 언제든 다시 볼 수 있으며 확인 기록과 필터 설정에는 영향을 주지 않습니다. 여러 탭은 하나의 안내 표시 권한을 공유합니다.

설정 팝업의 ‘확장 프로그램 설명’과 ‘인장 기준 설정’은 접음·펼침 상태를 각각 기기에 저장하며, 처음 사용 시에는 모두 펼쳐집니다.

추천확인 명단을 펼치면 닉네임 앞에 판정 동그라미를 표시합니다. 명단에는 인증마크가 없으므로 마크 부재만으로 노인장으로 판단하지 않습니다. 유효한 검증 캐시를 먼저 사용하고, 없는 사용자만 기존 대기열(최대 100명, 동시 10명)에 순차 제출합니다. 진행 중인 동일 닉네임 검증과 캐시는 게시글·댓글·다른 탭과 공유합니다. 명단을 닫으면 추가 제출을 멈추며 이미 제출된 검증은 완료될 수 있습니다. 게시글·댓글 숨김 설정은 명단에 적용하지 않으며 추천·비공감 명단의 동그라미는 상태 패널 집계에서 제외됩니다. 각 명단 제목 오른쪽에 검은색 합계와 초록·노랑·빨강·회색 동그라미별 인원수를 네 자리(9,999) 고정 폭으로 별도 표시하며 검증 진행과 기준 변경에 따라 갱신합니다. 같은 명단 안의 동일 닉네임은 한 명으로 계산합니다. 추가 권한은 없습니다.

현재 폴더는 0.6.0 웹스토어 업로드용입니다. 웹스토어의 기존 공개 버전은 새 버전이 심사·게시될 때까지 유지됩니다.

## 0.5.7 상태 패널과 색상 필터 분리

상태 패널 표시를 설정에서 켜고 끌 수 있으며, 스위치 왼쪽의 좌측·우측 네모 버튼에서 위치를 선택할 수 있습니다. 이미 선택된 버튼을 다시 누르면 반대 위치로 전환되며, 패널 표시 스위치 아래에는 켜기·끄기가 표시됩니다. 기본 위치는 우측하단이고 변경은 즉시 적용됩니다. 게시글·댓글 필터는 상태 패널 설정 아래에 배치하고 필터 적용·필터 꺼짐 상태를 표시합니다. 패널 숨김은 조회·닉네임 색상·필터를 중단하지 않습니다. 색상별 표시 설정은 게시글과 댓글로 분리했으며, 새 설정이 없으면 기존 색상 설정을 양쪽에 이어받습니다. Chrome 확장 관리에서 기존 항목을 새로고침한 뒤 인벤 탭을 새로고침하세요.

로스트아크 인벤의 공개 인장과 게임 프로필 정보를 확인해 작성자 닉네임에 상태를 표시하고 게시글·댓글을 필터링하는 Chrome Manifest V3 확장 프로그램입니다.

인벤이나 스마일게이트의 사전 승인을 받지 않은 비공식 확장 프로그램입니다.

## 판정과 설정

- 초록: 공개 프로필이 갱신 기간·전투력·아이템 레벨 기준을 모두 충족
- 노랑: 공개 프로필은 있지만 설정 기준을 하나 이상 충족하지 않음
- 빨강: 인증마크가 없거나 공개 인장에서 로아 프로필을 확인할 수 없음
- 회색: 판정 대기·실패·일부 정보 확인 불가

기본 기준은 최근 갱신 3개월 이내, 전투력 4,000 이상, 아이템 레벨 1,730 이상이며 사용자가 변경할 수 있습니다. 게시글·댓글 필터와 색상별 숨김을 각각 설정하고 전체 기능을 끌 수 있습니다. 기본적으로 초록·노랑은 표시하고 빨강·회색은 숨깁니다. 목록의 기존 인증마크는 판정용 DOM을 남긴 채 화면에서만 숨깁니다.

목록·댓글은 인증마크가 없으면 조회 없이 빨강으로 판정합니다. 상세 작성자 영역은 인증마크를 출력하지 않는 구조이므로 실제 프로필을 조회합니다. 조회가 필요한 사용자는 인장 페이지의 로아 프로필 항목과 실제 프로필 응답을 함께 확인합니다. 상세 작성자, 댓글, 목록 작성자 순으로 제출합니다.

캐시는 정상 30분, 실패 30초입니다. 전체 탭에 걸쳐 대기·진행 최대 100명, 동시 10명으로 제한하고 요청 제한 응답 시 잠시 중단합니다. 상태 패널 숫자는 고유 사용자 수가 아니라 현재 페이지의 닉네임 표시 수이며 동일 작성자의 중복 표시를 포함합니다.

## 설치

웹스토어 공개 전에는 배포 ZIP을 풀고 chrome://extensions 에서 개발자 모드를 켠 뒤 ‘압축해제된 확장 프로그램을 로드합니다’를 눌러 manifest.json이 들어 있는 폴더를 선택합니다. 설치·재로드 후 인벤 탭을 새로고침합니다. 공개 후에는 스토어 링크를 안내합니다.

지원 주소: https://www.inven.co.kr/board/lostark/ 및 https://m.inven.co.kr/board/lostark/ 게시판. 모바일 사이트의 목록·상세 작성자·동적 댓글을 지원하며 다른 게임 게시판은 제외합니다. 구형 powerbbs.php 주소는 /board/lostark/ 주소로 이동해 사용하세요. 모바일 페이지 지원은 모바일 Chrome의 확장 설치 지원을 뜻하지 않습니다. 실제 휴대폰 브라우저의 설치·호환성은 별도 확인이 필요합니다. 상태 패널의 설정 버튼은 Chrome 127 이상에서 지원하며 이전 환경은 도구 모음 아이콘을 사용하세요.

## 개인정보와 권한

설정·판정 결과는 PC의 확장 전용 로컬 저장소에 저장합니다. 필요한 닉네임·회원 식별자는 인벤의 조회 주소로 전송하지만 개발자 서버나 광고·분석 서버로 전송하지 않습니다. 본문·댓글·비밀번호·로그인 쿠키를 저장하지 않습니다.

Chrome API 권한은 storage 하나이며 서버 조회를 위해 HTTPS www.inven.co.kr 및 m.inven.co.kr 접근 권한이 필요합니다. 공개 프로필 조회는 기존 www.inven.co.kr의 두 조회 주소만 사용합니다. 자동 실행 범위와 실제 통신 주소는 코드에서 제한합니다. 자세한 처리 항목·캐시 삭제 방법은 [개인정보처리방침](PRIVACY.md), 자체 점검은 [보안 설명](SECURITY.md)을 참고하세요.

## 판정의 한계

색상은 인벤이 제공하는 공개 정보와 설정 기준의 결과입니다. 실제 게임 접속 여부나 개인의 신뢰성·행동을 보증하지 않습니다. 비공개와 미등록을 항상 구분할 수 없으며, 사이트 구조 변경·잘못된 원본 정보·통신 오류로 오판할 수 있습니다. 회색 표시를 켜면 판정 대기·실패 항목을 확인할 수 있습니다.
