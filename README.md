# 로벤 인장 필터 0.5.6

로스트아크 인벤의 공개 인장과 게임 프로필 정보를 확인해 작성자 닉네임에 상태를 표시하고 게시글·댓글을 필터링하는 Chrome Manifest V3 확장 프로그램입니다.

인벤이나 스마일게이트의 사전 승인을 받지 않은 비공식 확장 프로그램입니다.

## 판정과 설정

- 초록: 공개 프로필이 갱신 기간·전투력·아이템 레벨 기준을 모두 충족
- 노랑: 공개 프로필은 있지만 설정 기준을 하나 이상 충족하지 않음
- 빨강: 인증마크가 없거나 공개 인장에서 로아 프로필을 확인할 수 없음
- 회색: 판정 대기·실패·일부 정보 확인 불가

기본 기준은 최근 갱신 3개월 이내, 전투력 4,000 이상, 아이템 레벨 1,730 이상이며 사용자가 변경할 수 있습니다. 게시글·댓글 필터와 색상별 숨김을 각각 설정하고 전체 기능을 끌 수 있습니다. 기본적으로 초록·노랑은 표시하고 빨강·회색은 숨깁니다. 목록의 기존 인증마크는 판정용 DOM을 남긴 채 화면에서만 숨깁니다.

목록·댓글은 인증마크가 없으면 조회 없이 빨강으로 판정합니다. 상세 작성자 영역은 인증마크를 출력하지 않는 구조이므로 실제 프로필을 조회합니다. 조회가 필요한 사용자는 인장 페이지의 로아 프로필 항목과 실제 프로필 응답을 함께 확인합니다. 상세 작성자, 댓글, 목록 작성자 순으로 제출합니다.

캐시는 정상 30분, 실패 30초입니다. 전체 탭에 걸쳐 대기·진행 최대 100명, 동시 10명으로 제한하고 요청 제한 응답 시 잠시 중단합니다. 상태 패널 숫자는 고유 사용자 수가 아니라 현재 페이지의 닉네임 표시 수이며 동일 작성자의 중복 표시를 포함합니다.

## 설치

웹스토어 공개 전에는 배포 ZIP을 풀고 chrome://extensions 에서 개발자 모드를 켠 뒤 ‘압축해제된 확장 프로그램을 로드합니다’를 눌러 manifest.json이 들어 있는 폴더를 선택합니다. 설치·재로드 후 인벤 탭을 새로고침합니다. 공개 후에는 스토어 링크를 안내합니다.

지원 주소: https://www.inven.co.kr/board/lostark/ 의 PC 게시판. 상태 패널의 설정 버튼은 Chrome 127 이상에서 지원하며 이전 환경은 도구 모음 아이콘을 사용하세요.

## 개인정보와 권한

설정·판정 결과는 PC의 확장 전용 로컬 저장소에 저장합니다. 필요한 닉네임·회원 식별자는 인벤의 조회 주소로 전송하지만 개발자 서버나 광고·분석 서버로 전송하지 않습니다. 본문·댓글·비밀번호·로그인 쿠키를 저장하지 않습니다.

Chrome API 권한은 storage 하나이며 서버 조회를 위해 HTTPS www.inven.co.kr 접근 권한이 필요합니다. 자동 실행 범위와 실제 통신 주소는 코드에서 제한합니다. 자세한 처리 항목·캐시 삭제 방법은 [개인정보처리방침](PRIVACY.md), 자체 점검은 [보안 설명](SECURITY.md)을 참고하세요.

## 판정의 한계

색상은 인벤이 제공하는 공개 정보와 설정 기준의 결과입니다. 실제 게임 접속 여부나 개인의 신뢰성·행동을 보증하지 않습니다. 비공개와 미등록을 항상 구분할 수 없으며, 사이트 구조 변경·잘못된 원본 정보·통신 오류로 오판할 수 있습니다. 회색 표시를 켜면 판정 대기·실패 항목을 확인할 수 있습니다.
