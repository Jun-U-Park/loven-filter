# 로벤 인장 필터 0.6.7

로스트아크 인벤 자유게시판에서 인장과 실제 게임 프로필을 확인해 닉네임 옆에 색상을 표시하고 게시글·댓글을 필터링하는 Chrome Manifest V3 확장 프로그램입니다. 인벤이나 스마일게이트의 사전 승인을 받은 공식 프로그램이 아닙니다.

## 0.6.7 업데이트

1. 댓글 '공감 확인' 명단 통계 추가
2. 노인장 중복 집계 오류 수정
3. 게시글 화면의 통계 패널은 댓글만 집계하도록 변경
4. 페이지 이동 시 사용성 개선

## 지원 주소와 설치

PC www.inven.co.kr 및 모바일 m.inven.co.kr의 /board/lostark/6271, /board/webzine/6271 목록·상세 주소만 지원합니다. 팁·질문·직업 게시판 등 다른 게시판은 지원하지 않습니다. 모바일 페이지 지원은 모바일 Chrome에서 확장 설치가 가능하다는 뜻이 아닙니다.

기존 개발자 모드 폴더를 사용하는 경우 chrome://extensions에서 확장을 새로고침한 뒤 인벤 탭도 새로고침합니다. 새로 설치한다면 ZIP을 풀고 manifest.json이 있는 폴더를 ‘압축해제된 확장 프로그램을 로드합니다’로 선택합니다. 현재 배포 준비 버전은 0.6.7입니다. 기존 웹스토어 상품을 업데이트하며 심사 제출·게시는 별도로 진행합니다.

## 판정과 설정

- 초록: 공개 프로필이 갱신 기간·전투력·아이템 레벨 기준을 모두 충족
- 노랑: 공개 프로필은 있지만 설정 기준을 하나 이상 충족하지 않음
- 빨강: 인증마크가 없거나 인장에서 로아 프로필을 확인할 수 없음
- 회색: 판정 대기·실패·일부 정보 확인 불가

기본 기준은 최근 갱신 3개월 이내, 전투력 4,000 이상, 아이템 레벨 1,730 이상이며 설정에서 바꿀 수 있습니다. 세 조건을 모두 만족해야 초록색입니다. 목록·댓글은 인증마크가 없으면 조회 없이 빨강으로 표시하고, 마크를 제공하지 않는 상세 작성자·추천확인 명단은 실제 인장을 조회합니다. 기존 인증마크는 판정용 DOM을 보존하고 목록 화면에서만 숨깁니다.

게시글·댓글 필터와 색상별 표시·숨김을 각각 설정합니다. 전체 스위치를 끄면 조회를 중단하고 숨긴 항목을 복원합니다. 통계 패널 표시·숨김 및 좌측·우측 위치를 선택할 수 있습니다. 패널 숨김은 필터와 검증을 중단하지 않습니다. 설명·인장 기준 설정의 접음·펼침 상태는 각각 저장되며 처음에는 펼쳐집니다.

추천·비공감 명단은 펼쳤을 때 캐시를 먼저 확인하고 필요한 사용자만 조회합니다. 각 명단 제목 오른쪽에 검은색 합계와 색상별 인원수를 9,999까지 고정 폭으로 표시하며, 같은 명단의 같은 닉네임은 한 명으로 계산합니다. 명단 통계는 하단 통계 패널에 합산하지 않습니다. 하단 패널은 상세화면에서 댓글 작성자만, 목록 화면에서 목록 작성자를 닉네임별로 한 명씩 집계합니다.

정상 검증 결과는 최대 6시간·4만 명분을 보관합니다. 저장 크기를 보수적으로 계산해 약 7MiB에서 정리하고, 만료된 결과와 오래된 결과부터 삭제해 약 6MiB 이하로 여유를 확보합니다. 따라서 용량에 따라 4만 명보다 적게 유지될 수 있습니다. 사용자 설정과 유효한 실패 재시도 기록은 이 정리에서 삭제하지 않습니다. 추가 권한은 없습니다.

## 서버 요청과 데이터

전체 탭에서 진행·대기 고유 사용자 최대 20명, 동시 검증 최대 5명입니다. 새 사용자 검증을 최소 500ms 간격으로 시작하며 같은 사용자의 인장 응답 후 프로필 조회에는 추가 대기 시간을 두지 않습니다. 조회 제한 응답은 잠시 중단합니다. 상세 작성자·댓글·목록 순으로 검증하고 추천 명단은 그 뒤에 제출합니다. 정상 캐시는 6시간, 실패 캐시는 기본 30초(총 3회 실패 시 마지막 실패 후 30분까지 재시도 중단) 유효하며 동일 닉네임의 진행 중 검증과 캐시를 공유합니다. ‘인장 검증 새로고침’은 판정 캐시와 실패 횟수를 지우고 현재 화면을 다시 검증합니다.

Chrome API 권한은 storage 하나입니다. HTTPS www.inven.co.kr 및 m.inven.co.kr 호스트 권한이 있지만 자동 실행·메시지 검증은 자유게시판으로 제한하며, 프로필 통신은 www.inven.co.kr의 인장·게임 프로필 두 경로만 사용합니다. 로그인 쿠키·리퍼러를 제외하며 응답을 코드로 실행하지 않습니다. 개발자 서버·광고·분석·원격 코드 기능이 없습니다. 자세한 사항은 [개인정보처리방침](PRIVACY.md), [보안 설명](SECURITY.md)을 참고하세요.

## 업데이트 안내 내역 누적 규칙

0.6.1부터 같은 0.6.x 개발 버전의 변경사항을 계속 누적합니다. 새 버전에서는 release-notes.js의 현재 batches에 버전별 entries를 추가하며 기존 내역을 삭제·교체하지 않습니다. 자동 안내와 ‘업데이트 내역 보기’는 같은 누적 목록을 사용합니다. 과거 변경 기록의 지원 범위·요청 수치는 해당 버전 당시 기준이며 현재 동작은 이 문서의 설명을 기준으로 합니다.

사용자가 ‘배포버전’으로 확정하면 해당 버전까지의 내역을 고정하고 다음 개발 버전부터 새 묶음을 시작합니다. 0.7.x처럼 두 번째 버전 숫자가 바뀌어도 새 묶음을 시작하며 이전 기록은 보존합니다. 단순한 버전 증가만으로 배포버전으로 취급하지 않습니다.

## 새 설치 기본값

프로그램·게시글 필터·댓글 필터는 켜져 있고, 모든 색상 게시글·댓글을 표시합니다. 통계 패널은 꺼져 있으며 켜면 기본 우측 하단에 표시합니다. 설명과 인장 기준 설정은 펼쳐져 있습니다. 기존 사용자의 저장 설정은 유지합니다.

0.6.7은 배포 안내 묶음을 닫았습니다. 이후 개발 버전은 새 묶음으로 누적합니다.
