# 로벤 인장 필터 0.6.3

로스트아크 인벤 자유게시판에서 공개 인장과 실제 게임 프로필을 확인해 닉네임 옆에 색상을 표시하고 게시글·댓글을 필터링하는 Chrome Manifest V3 확장 프로그램입니다. 인벤이나 스마일게이트의 사전 승인을 받은 공식 프로그램이 아닙니다.

## 0.6.3 — 2026-10-22

500ms 제한을 새 사용자 검증 시작 간격에 적용하도록 조정했습니다. 같은 사용자의 인장 응답을 받고 로아 프로필 항목이 확인되면 추가 대기 없이 게임 프로필을 조회합니다. 동시 검증 최대 5명, 진행·대기 최대 100명, 자유게시판 6271 제한과 설정·캐시는 유지합니다.

## 0.6.2 — 2026-10-22

인벤 운영팀의 요청에 따라 동시 검증 인원을 최대 5명으로 줄이고, 인장 GET·게임 프로필 POST를 합친 실제 서버 요청 시작 간격을 전체 탭에 걸쳐 최소 500ms로 제한했습니다. PC·모바일 모두 자유게시판 번호 6271에서만 실행하며 lostark·webzine 주소를 지원합니다. 다른 로아 게시판에서도 표시·조회하지 않습니다. 캐시·설정과 진행·대기 100명 상한을 유지합니다.

## 지원 주소와 설치

PC www.inven.co.kr 및 모바일 m.inven.co.kr의 /board/lostark/6271, /board/webzine/6271 목록·상세 주소만 지원합니다. 팁·질문·직업 게시판 등 다른 게시판은 지원하지 않습니다. 모바일 페이지 지원은 모바일 Chrome에서 확장 설치가 가능하다는 뜻이 아닙니다.

기존 개발자 모드 폴더를 사용하는 경우 chrome://extensions에서 확장을 새로고침한 뒤 인벤 탭도 새로고침합니다. 새로 설치한다면 ZIP을 풀고 manifest.json이 있는 폴더를 ‘압축해제된 확장 프로그램을 로드합니다’로 선택합니다. 0.6.3을 배포버전으로 확정했습니다. 웹스토어 심사 제출·게시는 별도로 진행합니다. 0.6.0은 배포 전 취소되어 해당 변경사항을 0.6.3 안내에 함께 포함했습니다.

## 판정과 설정

- 초록: 공개 프로필이 갱신 기간·전투력·아이템 레벨 기준을 모두 충족
- 노랑: 공개 프로필은 있지만 설정 기준을 하나 이상 충족하지 않음
- 빨강: 인증마크가 없거나 인장에서 로아 프로필을 확인할 수 없음
- 회색: 판정 대기·실패·일부 정보 확인 불가

기본 기준은 최근 갱신 3개월 이내, 전투력 4,000 이상, 아이템 레벨 1,730 이상이며 설정에서 바꿀 수 있습니다. 세 조건을 모두 만족해야 초록색입니다. 목록·댓글은 인증마크가 없으면 조회 없이 빨강으로 표시하고, 마크를 제공하지 않는 상세 작성자·추천확인 명단은 실제 인장을 조회합니다. 기존 인증마크는 판정용 DOM을 보존하고 목록 화면에서만 숨깁니다.

게시글·댓글 필터와 색상별 표시·숨김을 각각 설정합니다. 전체 스위치를 끄면 조회를 중단하고 숨긴 항목을 복원합니다. 통계 패널 표시·숨김 및 좌측·우측 위치를 선택할 수 있습니다. 패널 숨김은 필터와 검증을 중단하지 않습니다. 설명·인장 기준 설정의 접음·펼침 상태는 각각 저장되며 처음에는 펼쳐집니다.

추천·비공감 명단은 펼쳤을 때 캐시를 먼저 확인하고 필요한 사용자만 조회합니다. 각 명단 제목 오른쪽에 검은색 합계와 색상별 인원수를 9,999까지 고정 폭으로 표시하며, 같은 명단의 같은 닉네임은 한 명으로 계산합니다. 명단 통계는 하단 통계 패널에 합산하지 않습니다. 하단 패널은 게시글·댓글의 닉네임 표시 수로, 같은 사용자가 여러 곳에 보이면 중복 집계합니다.

## 서버 요청과 데이터

전체 탭에서 진행·대기 고유 사용자 최대 100명, 동시 검증 최대 5명입니다. 새 사용자 검증을 최소 500ms 간격으로 시작하며 같은 사용자의 인장 응답 후 프로필 조회에는 추가 대기 시간을 두지 않습니다. 조회 제한 응답은 잠시 중단합니다. 상세 작성자·댓글·목록 순으로 검증하고 추천 명단은 그 뒤에 제출합니다. 정상 캐시는 30분, 실패 캐시는 30초 유효하며 동일 닉네임의 진행 중 검증과 캐시를 공유합니다. ‘인장 검증 새로고침’은 판정 캐시를 지우고 현재 화면을 다시 검증합니다.

Chrome API 권한은 storage 하나입니다. HTTPS www.inven.co.kr 및 m.inven.co.kr 호스트 권한이 있지만 자동 실행·메시지 검증은 자유게시판으로 제한하며, 프로필 통신은 www.inven.co.kr의 인장·게임 프로필 두 경로만 사용합니다. 로그인 쿠키·리퍼러를 제외하며 응답을 코드로 실행하지 않습니다. 개발자 서버·광고·분석·원격 코드 기능이 없습니다. 자세한 사항은 [개인정보처리방침](PRIVACY.md), [보안 설명](SECURITY.md)을 참고하세요.

## 업데이트 안내 내역 누적 규칙

0.6.1부터 같은 0.6.x 개발 버전의 변경사항을 계속 누적합니다. 새 버전에서는 release-notes.js의 현재 batches에 버전별 entries를 추가하며 기존 내역을 삭제·교체하지 않습니다. 자동 안내와 ‘업데이트 내역 보기’는 같은 누적 목록을 사용합니다. 과거 변경 기록의 지원 범위·요청 수치는 해당 버전 당시 기준이며 현재 범위는 이 문서 상단의 0.6.2 기준입니다.

사용자가 ‘배포버전’으로 확정하면 해당 버전까지의 내역을 고정하고 다음 개발 버전부터 새 묶음을 시작합니다. 0.7.x처럼 두 번째 버전 숫자가 바뀌어도 새 묶음을 시작하며 이전 기록은 보존합니다. 단순한 버전 증가만으로 배포버전으로 취급하지 않습니다.

### 0.6.3 업데이트 안내 문구 정리

0.6.0은 배포 전에 취소되었으므로 해당 기능 변경 내역도 현재 안내에 포함합니다.

1. 게시글/댓글 숨김 옵션 분리
2. 화면 하단 통계 패널 표시/숨김 옵션 추가
3. 게시글 내 추천 확인 시 명단 색상 및 통계 추가
4. 로스트아크 자유게시판에서만 작동하도록 수정
5. 메인 화제글의 webzine 주소에서 필터가 작동하지 않던 문제 수정
6. 인벤 측 서버 부담을 줄이기 위한 요청 처리 방식 조정

이 목록은 사용자가 승인한 누적 안내 요약입니다. 기존 버전별 기록은 보존합니다. 이번 배포 내역은 위 6개 항목으로 고정합니다. 0.6.3 배포버전으로 확정해 이 목록을 고정했습니다. 다음 개발 버전부터 새 누적 묶음을 시작합니다.
